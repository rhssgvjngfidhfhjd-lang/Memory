说明（与 4 操作版的差异）：
- 每个 chunk 保证产出记忆：模型输出不可用时自动把原始 chunk 文本兜底插入，log 里的 fallback_inserts_this_run 应接近 0。
- 预期 final_memories ≈ 3962（每 dataset 记忆数约等于 event 数，模型一轮拆多条时更多），compression_ratio ≈ 1.0，这是 insert-only 的定义使然，不是异常。
- 健康检查：每个 dataset 完成时 log 打印一行 JSON 统计，确认 action_counts 只有 INSERT、parse_failures 接近 0、enabled_operations 为 ["insert"]。
